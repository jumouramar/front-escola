# Desenvolvimento - Front Escola

### ✅ 0. Pré-requisitos

- node==22.20.0

### 🚀 1. Criar o Projeto

```bash
npm create vite@latest
```

- Nome do projeto: nome-projeto
- Framework: React
- Variante: TypeScript + SWC

Depois:

```bash
cd nome-projeto
npm install
```

### 🛠️ 2. Instalar depêndencias

Bootstrap

```bash
npm install bootstrap
```

React Router Dom

```bash
npm install react-router-dom
```

Fontawesome

```bash
npm install @fortawesome/fontawesome-free
```

```bash
npm install @tanstack/react-query
```

React Form

```bash
npm install react-hook-form
```

Zod

```bash
npm install @hookform/resolvers react-hook-form zod
```

```bash
npm install zustand
```

npm i bootstrap-icons

### ▶️ 3. Rodar o Projeto

```bash
npm run dev
```
